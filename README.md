# Invitación lista para subir a la nube

He dejado la invitación preparada como una página estática en [index.html](index.html).

## Qué necesitas subir

Sube toda esta carpeta a tu hosting estático, manteniendo esta estructura:

- [index.html](index.html)
- [Muestra Azure - Invitali.html](Muestra Azure - Invitali.html)
- [Muestra Azure - Invitali_files/](Muestra%20Azure%20-%20Invitali_files)
- [lorena_context.txt](lorena_context.txt)
- [search_names.txt](search_names.txt)
- [search_name_context.txt](search_name_context.txt)
- [gift_section_snippet.txt](gift_section_snippet.txt)
- [find_times.py](find_times.py)

## Opción 1: Netlify

1. Ve a https://app.netlify.com
2. Haz clic en "Add new site" > "Deploy manually"
3. Arrastra esta carpeta completa
4. Espera a que termine la carga
5. Netlify te dará una URL pública

## Opción 2: Cloudflare Pages

1. Ve a https://pages.cloudflare.com
2. Crea un proyecto nuevo
3. Sube la carpeta completa
4. Publica el proyecto
5. Usa la URL que te genere

## Opción 3: GitHub Pages

1. Sube esta carpeta a un repositorio de GitHub
2. En la configuración del repositorio activa GitHub Pages
3. Selecciona la rama principal y la carpeta raíz
4. La invitación quedará disponible en una URL pública

## Nota importante

La invitación ya tiene las referencias a los recursos locales dentro de la carpeta `Muestra Azure - Invitali_files`, por lo que no necesitas cambiar nada si subes la carpeta completa intacta.

## Enlace para invitar

Cuando la URL pública esté activa, puedes compartirla directamente con tus invitados.
